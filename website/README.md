# Hello from the workbench

This little page introduces Oopsware and points to its source, instructions,
license, and original authors. It is plain HTML and CSS. It needs no build,
tracking service, signup, or package download.

```sh
python3 scripts/website.py check
python3 scripts/website.py serve
```

Open <http://127.0.0.1:4173/>. The preview binds to this computer only. The
analysis app is separate: `node scripts/oopsware.mjs web --port 4097`.

The inherited promotional site, social channels, published-release claims,
and deployment setup were retired. Its original case studies are still
available in [REA's source history](https://github.com/morluto/rea/tree/main/website),
credited to the original project. They are not CSR verification results.

No public website has been deployed for Oopsware.
