# A small front door

This is a local, static companion to the workbench. Keep the voice curious,
plain, and useful. No sales pitch, social counters, tracking, or claims of
published packages. Keep credit for REA and its authors visible.

Edit `public/index.html` and `public/styles.css`. Run
`python3 scripts/website.py check` and preview with
`python3 scripts/website.py serve`. Check desktop and narrow layouts.
There is no configured public host or publishing workflow. Never use GitHub
Actions. Publishing requires an explicit request and a real destination.
