About

An open library for the curious

Bring a file. See what it's made of. Share what you find. No account, nothing to buy.

What this is

Oopsware is a workbench for taking software apart and understanding how it works. This site is its public library: anyone can upload a file, the library inspects it without running it, and anyone can browse the findings and download the file or the pieces found inside it.

How to use it

  • Browse the library and open any file to read its findings.
  • Upload something you have the right to share. It's inspected automatically.
  • See File types for exactly what you get for each kind of file.

Honest by design

The library separates what it observed from what it could not determine. A file being inspected never means it was run, and never means it was judged safe. Deep analysis — disassembly, decompiling — happens in the desktop tool with a provider you install, not on this public service.

Credit

Oopsware is an independent fork of REA — Reverse Engineer Anything, created by morluto and the REA contributors. The original command-line tool, analysis engine, and provider integrations came from that work, and it is credited and licensed in the project's repository. Thank you to everyone who built it.

Provider names such as Hopper, Ghidra, IDA, jadx, and apktool belong to their own projects; they are separate tools, not part of Oopsware.

Open-source apps in the library

These apps came from their projects' official releases. Disk-image (.dmg) downloads were checked against the checksum the project publishes; apps repackaged as a zip of the app folder (so you can look inside) were instead confirmed by their Apple-notarized code signature, since repackaging changes the bytes. Either way the files are unchanged. Each app keeps its own license and name, and each source link points to the code for that exact version.
