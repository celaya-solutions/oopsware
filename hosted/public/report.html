Report a file

See something that shouldn't be here? Tell us and we'll take it down.

The library is for files people have the right to share. If something infringes your copyright, contains personal data, or otherwise shouldn't be public, ask us to remove it. We act on reports promptly.

Email hello@celayasolutions.com with:

  • The link to the file (copy it from the file's details), or its name.
  • Why it should be removed — for example, you own the copyright, or it contains personal data.
  • A way to reach you if we need to follow up.

Open a takedown email →

A faster option

Most uploads are set to delete themselves 24 hours after they go up, so many files clear on their own within a day. If a file is set to stay and shouldn't, the email above is the way to reach a person.

Abuse and security

To report misuse of the service or a security issue, use the same address and say so in the subject.
