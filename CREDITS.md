# Credit where the curiosity started

Oopsware is an independent CSR fork of
[REA — Reverse Engineer Anything](https://github.com/morluto/rea), created by
**morluto and the REA contributors**. The original CLI, MCP tools, analysis
architecture, provider integrations, tests, and technical guides came from
that work. Thank you for making them available.

The original copyright is **Copyright (c) 2026 morluto**. Its complete MIT
license is kept unchanged in [LICENSES/REA-MIT.txt](LICENSES/REA-MIT.txt).
The [upstream history](https://github.com/morluto/rea/commits/main/) records
individual contributions.

**Celaya Solutions** maintains the CSR fork, including its local web
workbench, subsequent changes, and the Oopsware name and writing. The
pre-rebrand MIT baseline is CSR commit
`86b180f332bcb34e32bc13454e75b0cdb6883568`. Code already covered by MIT at that
point stays covered by MIT; new CSR contributions from this rebrand onward
use the terms in [LICENSE](LICENSE).

Original evidence notes and captured verification results retain their
target identities, dates, versions, and authorship. They record earlier
investigations, not new Oopsware test runs. Where an upstream issue explains
a technical constraint, its link stays intact.
